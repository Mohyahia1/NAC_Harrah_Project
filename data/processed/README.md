# data/processed

Small crops only, GeoTIFF with CRS, raw elevation in metres (no normalization).
Naming: `<world>_<target_or_site>_dem.tif`, e.g. `moon_marius_pit_dem.tif`, `mars_jezero_dem.tif`, `earth_al_wahbah_dem.tif`.
Add one line per file to `sources.csv`: file, dataset, download URL, download date.
