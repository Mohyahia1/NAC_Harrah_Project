# data/raw (not in git)

Large source files stay on the team's Google Drive (Cave_Finder folder, owner: Ryouf):
- ASTER GDEM v3 tiles: N21E042, N21E050, N22E041, N23E039, N25E039, N27E037 (+ num files)
- Processed ASTER GeoTIFFs (elevation, slope, roughness) per tile
- Global LOLA (ldem_16) and MOLA (megt90n000eb) and Ryouf's derived arrays

To run the pipeline locally, download the files you need into this folder. Only small crops go to `data/processed/`.
